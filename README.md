# Менеджер посилань у Telegram

Варіант 7. У приватному чаті користувач надсилає адресу й тег, а потім знаходить усі свої посилання за цим тегом. За одним тегом можна зберегти кілька адрес.

## Запуск на Windows

1. Завантаж ZIP і розпакуй його. Відкрий папку з `Gemfile` та `bot.rb` у Провіднику, введи `powershell` в адресний рядок і натисни Enter. Якщо проєкт уже опубліковано на GitHub або GitLab, його також можна отримати командою `git clone <URL-репозиторію>` та перейти до завантаженої папки.
2. Виконай `ruby -v` та `bundle -v`. Якщо Ruby відсутній, встанови **Ruby+Devkit 3.4 x64** із [RubyInstaller](https://rubyinstaller.org/downloads/), потім відкрий новий PowerShell у папці проєкту. Якщо відсутній лише Bundler, виконай `gem install bundler`.
3. Виконай `bundle install`.
4. Відкрий у Telegram [@BotFather](https://t.me/BotFather). Надішли `/newbot`, введи назву та вільний username із закінченням `bot`. Скопіюй отриманий токен.
5. У PowerShell виконай команду нижче. Встав токен у прихований запит і натисни Enter. Змінна діє до закриття цього вікна.

```powershell
$env:TELEGRAM_BOT_TOKEN = [System.Net.NetworkCredential]::new('', (Read-Host 'Токен від BotFather' -AsSecureString)).Password
```

6. У тому ж вікні виконай `bundle exec ruby bot.rb`. Після повідомлення про підключення відкрий бота за username і натисни **Start**. Бот працює, поки запущений скрипт. Для зупинки натисни **Ctrl+C**.

## Команди

| Команда | Результат |
| --- | --- |
| `/start` або `/help` | Показує призначення бота й приклади команд. |
| `/save https://www.ruby-lang.org ruby` | Записує адресу за тегом ruby. |
| `/get ruby` | Повертає кожну знайдену адресу окремим повідомленням. |

Тег складається з одного слова, допускає українські літери, цифри, дефіс і підкреслення. Наприклад, `/get #Навчання` та `/get навчання` дають однаковий результат.

## Як пояснити код

- `Gemfile` перелічує залежності. Гем `telegram-bot-ruby` забезпечує обмін повідомленнями через Telegram Bot API, а `sqlite3` працює з базою. Бот зберігає саму адресу, тому йому достатньо Telegram Bot API.
- У `bot.rb` виклик `get_me` перевіряє підключення. Далі `bot.listen` отримує повідомлення з Telegram, `reply_to` розбирає команду, а `send_message` повертає результат у приватний чат.
- `links.sqlite3` створюється автоматично поруч із програмою. Таблиця `links` зберігає ID користувача, тег та URL. Команда `/get` відбирає дані одночасно за користувачем і тегом. Записи доступні після перезапуску.
- Програма перевіряє формат URL і тегу. Обмеження `UNIQUE(user_id, tag, url)` запобігає повторному запису тієї самої адреси за тим самим тегом. Для порожньої вибірки та помилкової команди передбачено текстові підказки.

## Що показати на відео

1. До початку запису введи токен. Увімкни запис екрана і в терміналі запусти `bundle exec ruby bot.rb`, щоб у кадрі з’явилося підтвердження підключення.
2. У Telegram надішли по черзі команди нижче. Покажи, що за тегом ruby бот повернув обидві адреси.

```text
/start
/save https://www.ruby-lang.org ruby
/save https://rubygems.org ruby
/get ruby
```

3. Надішли `/save помилка ruby` і `/get порожньо`. Покажи підказку щодо адреси та відповідь для невідомого тегу.
4. У терміналі зупини бота через Ctrl+C, запусти повторно й надішли `/get ruby`. Покажи дві збережені адреси.
5. Коротко покажи `Gemfile` та в `bot.rb` гілки `/save` і `/get`. Поясни, як база зберігає посилання окремо для кожного користувача.

Для звіту додай доступне викладачу посилання на запис демонстрації. Якщо розгорнеш бота на постійному хостингу, додай сюди також його Telegram-посилання.
